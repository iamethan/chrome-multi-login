# Edge 扩展商店 — 提交素材

## 简短描述 (132 字符以内)

每个标签页拥有独立的登录态，同一网站可同时登录多个账号，互不干扰。

## 详细描述

Multi-Login Session Isolator 是一款轻量级的 Edge 浏览器扩展，为每个标签页创建独立的登录环境，让你可以在同一个浏览器窗口中同时使用多个账号。

### 主要功能

- **标签页级别 Cookie 隔离**：每个标签页维护独立的 Cookie 会话，切换标签时自动切换登录态
- **LocalStorage 隔离**：不仅隔离 Cookie，还隔离 LocalStorage 数据，确保完全独立
- **一键新建隔离标签**：通过弹出窗口快速创建新的隔离标签页，自动分配独立 Session
- **Session 管理**：为每个 Session 自定义名称，方便区分不同账号
- **一键重置**：快速清除当前标签的登录态，方便切换或重新登录
- **自动同步**：监听 Cookie 变化，实时同步到对应 Session

### 使用场景

- 同时管理多个社交媒体账号
- 开发者测试多用户角色切换
- 运营人员管理多个商家后台
- 任何需要同一网站登录多个账号的场景

### 使用方法

1. 点击工具栏扩展图标打开管理面板
2. 点击「新建隔离标签」创建独立会话
3. 在不同标签页登录不同账号
4. 自由切换标签，各账号登录态互不影响

### 隐私说明

所有数据均保存在浏览器本地（chrome.storage.local），不会上传到任何服务器，不收集任何用户信息。
